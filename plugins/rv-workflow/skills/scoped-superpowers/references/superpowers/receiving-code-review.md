# Receiving Code Review

Translate every review comment into a testable technical claim. Read the referenced code and verify whether the concern applies in this repository, version, and contract. Ask for clarification when a comment is ambiguous; challenge incorrect or scope-expanding advice with concrete evidence instead of performative agreement.

Prioritize correctness, security, and contract violations before style. Implement one coherent change at a time and run the narrowest meaningful check after each group. Do not weaken tests, add speculative abstractions, or accept a suggestion only because it sounds authoritative. Report which findings were applied, declined, or need a product decision and why.
