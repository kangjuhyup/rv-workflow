# Using the Bundled Workflows

Treat the scoped router as the only public entry point for Superpowers-derived guidance. Classify the task first, then load only the one internal reference that matches the current phase. Repository instructions and direct user requests take precedence. Small, clear, low-risk work should remain direct and should not inherit planning, delegation, or tracking overhead.

Explicit workflow requests are routed here as well; they do not authorize unrelated actions or automatically enable every phase. Re-evaluate when the phase changes and load another reference only if its trigger independently applies. Never require a separately installed Superpowers plugin.
